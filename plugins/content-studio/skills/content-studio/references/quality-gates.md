# Required acceptance gates

| Gate | Evidence | Pass condition |
|---|---|---|
| Brief | Assumptions and brief | Requested audience, scope and format |
| Facts | Source ledger | Claims supported or labeled opinion |
| Tools | All 17 evidence records | All required tools executed and outputs verified |
| Reproduction | Locks and commands | Dependencies and export settings recorded |
| Visual | Frames and review notes | No missing assets, unreadable text or cutoff |
| Motion | Repeated/out-of-order seek | Same frame reproduces |
| Language | Copy and caption review | Correct text, shaping, timing and direction |
| Audio | Listening and measurements | Expected sound intelligible and unclipped |
| Media | Helper report | Dimensions, fps, duration, expected audio and full decode |
| Delivery | Actual files and source | Outputs exist and limitations disclosed |

Use `passed`, `failed`, `blocked` or `not-applicable` with evidence. A script cannot pass visual, factual or listening review. Preserve blockers in delivery notes. Never claim all frameworks were exercised if only packaging or one renderer was tested.

Inspect first nonblank frame, middle/end of each scene, transitions and final frame. Check captions near cuts and long words. When a media viewer or listening tool is unavailable, keep extracted frames and report the exact review limits.
