# Lottie-web

Research checked: 2026-11-23. Verify installed versions before production.

Load locally licensed animation JSON and its assets. Disable loop/autoplay, await readiness, and sample with `goToAndStop(frame, true)` using the animation's frame rate. Test the selected SVG/Canvas renderer with the asset; After Effects features do not all transfer identically. Keep external media/font dependencies available before capture and destroy unused instances. Produce and inspect a sampled frame as integration evidence.

Starting command (run in the appropriate project/environment):

```sh
npm install --save-exact lottie-web
```
