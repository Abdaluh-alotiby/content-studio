Research checked: 2026-11-23. Verify installed versions before production.

Build paused timelines with labels, easing and staggered transitions. Seek in seconds from the renderer's shared clock. Never leave an infinite repeat in an offline capture. Keep layout setup separate from animated transforms. Clean up contexts/timelines in component lifecycles. Use plugins only when the installed version and current terms support them. Avoid scroll or pointer dependence in video exports; use explicit timeline inputs.
