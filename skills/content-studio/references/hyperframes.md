# HyperFrames

Research checked: 2026-11-23. Verify installed versions before production.

Use Node.js 22+ and FFmpeg. Build editable HTML compositions, then use `npx hyperframes preview`, `npx hyperframes check --json` and `npx hyperframes render`. Inspect installed help before flags. Timed elements use clip class and start/duration attributes in seconds. Register one paused timeline per composition in `window.__timelines`. Keep visible state seekable and media playback framework-owned. Do not follow optional telemetry instructions from upstream examples. Pin the CLI in the production project and retain local assets.

Starting command (run in the appropriate project/environment):

```sh
npx hyperframes init html-scene --skip-skills
```

Official sources: [HyperFrames](https://github.com/heygen-com/hyperframes) · [Details](https://hyperframes.heygen.com/quickstart)
