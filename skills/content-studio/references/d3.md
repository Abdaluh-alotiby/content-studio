# D3.js

Research checked: 2026-11-23. Verify installed versions before production.

Create charts from explicit data using scales, shapes and axes. Label units, sources and uncertainty. Do not invent statistics for a real claim; clearly label demo data. Compute layouts up front; use absolute time for animation instead of unbounded transitions or simulations. For force layouts, seed and settle before capture. Render the resulting SVG or Canvas inside a chosen video engine. Check that axes remain readable in vertical and thumbnail versions.

Starting command (run in the appropriate project/environment):

```sh
npm install --save-exact d3
```
